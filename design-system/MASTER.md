**팔레트(이름 있는 기본색 5)**

| 이름 | hex | 역할 |
|---|---|---|
| 먹(Ink) | `#172033` | 본문 글자 |
| 쪽빛(Jjok indigo) | `#1F3B73` | 주 행동 버튼, 링크, 선택 상태 |
| 작업대(Bench) | `#E9EEF5` | 입력 영역 바탕 |

쪽빛을 고른 이유: 판정 4색(빨강·주황·초록·회색)과 겹치지 않는 유일한 색상군이어서, 브랜드 색이 판정 의미와 섞이지 않는다. 보라(AI 템플릿·신뢰 훼손)는 배제.

**레이아웃 개념 — "작업대 + 판정서"**

```
데스크톱(≥1024)                                      모바일(<768)
┌ 헤더: 로고 | 입력 요약 판정표 서류 초안 ─────────┐  ┌ 로고 ───────────┐
├ 작업대(380px, sticky) ┬ 판정서(흰 종이) ───────┤  ├ 섹션 탭(sticky) ┤
│ h1 제목·설명           │ [예비 판정] 제품명(h2)   │  │ h1 · 입력         │
│ [데모 제품][직접 입력] │ 메타(dl)                 │  │ 판정 요약          │
│ 데모 4종 버튼          │ 판정 문장(24~28px)       │  │ 판정표(행=카드형) │
│ 판정 대상 필터         │ 등급 범례 띠(개수+정의)  │  │  보완 칩           │
│                        │ 가장 먼저 할 일 1~3      │  │ 서류 초안          │
│                        │ 중기부 지원 콜아웃       │  │ 고지문             │
│                        │ 판정표: 관할 그룹 + 보완 │  └──────────────────┘
│                        │   매트릭스 5칸           │
│                        │ 서류 초안 목록           │
│                        │ 고지문                   │
└────────────────────────┴──────────────────────────┘
```

정렬: 전부 왼쪽 정렬. 숫자 열(개수·신뢰도)만 표 형식 숫자(`tabular-nums`).

**원칙**
1. 대담함은 한 곳에만 — **보완 매트릭스**(재처방 / 서류·확인 / 현지 책임자 / 문구·라벨 / 시험). 등급 정의("불가=재처방", "조건부=서류·현지책임자·문구·시험 보완")를 그대로 열로 만든 장치다. 나머지는 조용하게.
2. 결과는 "판정서" 문서처럼 읽힌다 — 제품명, 기준일, 예비 판정 표시, 끝의 고지문.
3. 결론 먼저 — 숫자 대신 한 문장("대상 인증 7개 모두 재처방 없이 통과할 수 있습니다")이 첫 정보.
4. 쉬운 말, 합니다체, 같은 행동은 같은 이름(판정하기 → "판정 완료", 내려받기 → "내려받았습니다").

**검토에서 바꾼 것(일반 기본값 제거)**
- 등급별 개수를 카드 4장 → **한 줄 범례 띠**(세로 구분선)로. 같은 둥근 카드 반복 회피.
- 분포 막대·숫자 카운트업 애니메이션 → 삭제(대시보드 기본값, 정보 추가 없음).
- 메타 정보 "A · B · C" 문자열 → 정의 목록(dl)으로.
- 모든 제목 위 대문자 라벨, 모노스페이스 데이터 라벨, 버튼 끝 '→' → 쓰지 않음.
- 크림 바탕 + 테라코타 → 차가운 회색 바탕 + 흰 판정지.

### 4.3 타이포그래피

- 패밀리: `Pretendard Variable`(jsDelivr 동적 서브셋, `font-display: swap`) → `Pretendard, -apple-system, BlinkMacSystemFont, system-ui, "Apple SD Gothic Neo", "Noto Sans KR", "Malgun Gothic", "Hiragino Sans", "PingFang SC", sans-serif` (일본어·중국어 인증명 대비)
- 크기(rem, 브라우저 기본 글자 크기 설정을 따름): `--fs-12 .75rem` `--fs-14 .875rem` `--fs-16 1rem(본문)` `--fs-18 1.125rem` `--fs-20 1.25rem` `--fs-24 1.5rem` `--fs-28 1.75rem` `--fs-32 2rem`
- 줄바꿈: 문단 `text-wrap: pretty`(끝 한 단어 고아 방지), 제목·판정 문장 `text-wrap: balance`
- 굵기: 400 본문 / 500 레이블 / 600 제목 / 700 판정 문장·개수
- 줄높이: 본문 1.6, 제목 1.3, 표 행 1.5
- 자간: 본문 기본값, 24px 이상 제목만 -0.01em
- 한국어: `word-break: keep-all; overflow-wrap: break-word;` 전역
- 숫자: 개수·신뢰도·함량은 `font-variant-numeric: tabular-nums`

### 4.4 간격 (4pt)

`--sp-1 4` `--sp-2 8` `--sp-3 12` `--sp-4 16` `--sp-5 20` `--sp-6 24` `--sp-8 32` `--sp-10 40` `--sp-12 48` `--sp-16 64` (px)

### 4.5 반경 (위계별로 다르게)

`--r-xs 4px` 배지·칩·보완 표시 / `--r-sm 6px` 입력칸·버튼 / `--r-md 10px` 작업대 안 선택 목록·콜아웃 / `--r-lg 14px` 판정서 시트 / `--r-full 999px` 사용 안 함(원형 아이콘 버튼만)

### 4.6 그림자

`--sh-xs 0 1px 2px rgba(23,32,51,.06)` 버튼 / `--sh-sm 0 1px 3px rgba(23,32,51,.08), 0 1px 2px rgba(23,32,51,.04)` 판정서 시트 / `--sh-header 0 1px 0 var(--c-line-300)` 헤더 하단선. 카드마다 그림자 금지.

### 4.7 모션

`--dur-fast 120ms`(프레스·호버 종료) `--dur-base 160ms`(호버 시작) `--dur-open 180ms`(펼침) `--dur-enter 240ms`(결과 등장)
`--ease-out cubic-bezier(.2,0,0,1)` `--ease-in cubic-bezier(.4,0,1,1)`. transform·opacity만 애니메이션. `prefers-reduced-motion: reduce`면 0ms·smooth scroll 해제.

### 4.8 브레이크포인트·레이어·아이콘

- 브레이크포인트: 375 / 768(판정표 매트릭스 열 등장) / 1024(작업대+판정서 2단) / 1440(최대 폭 1440 컨테이너)
- z-index: `--z-sticky 10` 표 머리 / `--z-header 20` 헤더 / `--z-toast 30` 알림
- 아이콘: Lucide 인라인 SVG 스프라이트, stroke 2, 외곽선형만. 크기 `--ic-xs 14px`(칩 안) `--ic-sm 16px` `--ic-md 20px` `--ic-lg 24px`
- 터치 요소 간격: 나란한 터치 요소는 8px 이상(헤더 탭, 체크 항목, 필터 칩)

| 통과 가능 | 현재 상태로 통과 | circle-check | 옅은 바탕 (pass-050, 글자 pass-700) |
| 해당 없음 | 적용 대상 아님 | circle-minus | 바탕 없음 + 점선 테두리 (글자 na-700) |

모양(팔각형·삼각형·원+체크·원+가로선)·채움 정도·글자가 모두 달라 색각 이상에서도 구분된다.

**보완 범주(엔진 `classify.GAP_TYPES` 분류 → 화면 5열)** — 엔진 분류가 기준이고 화면은 5열로 묶기만 한다.

| 열 | 엔진 분류(gaps 키) |
|---|---|
| 재처방 | 재처방, 재처방(기한) |
| 서류·확인 | 서류, 서류(자동 초안), 원료 증명, 제조소 확인, 처방 확정, 성분 확인, 포장재, 회사 요건, 기타 |
| 현지 책임자 | 현지 책임자 |
| 문구·라벨 | 라벨, 표방 문구 |
| 시험 | 시험 |

열 제목과 같은 분류(서류·시험·현지 책임자·재처방)는 상세에서 태그를 달지 않고, 나머지(원료 증명·자동 초안 등)는 항목 옆 태그로 보여 준다.

**회사 단위 인증**(`kind: company_certification`, 메인비즈·이노비즈·벤처): 제품 처방과 무관하므로 요약 문장·등급 개수·재처방 이유·가장 먼저 할 일에서 뺀다. 요약 안 "회사 단위 인증" 목록과 판정표 맨 끝 "회사 단위" 그룹에만 둔다. 여기서 불가는 "회사 요건을 먼저 갖춰야 신청 가능"으로 설명한다.

**행의 핵심 사유**: 적용 인증의 절반 이상에 공통인 조치(현지 책임자·현지어 라벨 등 — 요약의 "가장 먼저 할 일"이 이미 다룸)는 뒤로 미루고, 그 인증에만 있는 사유(표방 문구, 원료, 포장재 등)를 먼저 보여 준다. 서류가 맨 앞이면 "필요 서류 N건: ○○ 등"으로 요약한다. 자동 초안 가능 서류(`DOC_DRAFTABLE`)는 "가장 먼저 할 일"에서 빼고 서류 초안 영역 안내 문구에서 개수로 알린다.

매트릭스 칸: 필요하면 작은 사각 표시 + 건수(2건 이상), 없으면 옅은 "–". 재처방 칸만 fail 색, 나머지는 먹색(주황 바다 방지). 스크린 리더용 문구 "서류·확인 3건".

**신뢰도**: ≥0.9 높음 / ≥0.6 보통 / 그 아래 낮음. 글자 + 퍼센트, 펼치면 낮춘 이유(ING_PROXY·ING_CN_SPEC_2015·ING_JP_NAME_ONLY·ING_NO_DATA·FORMULA_CONCEPT 메시지).

**AIStream 판정 모델(선택 기능)** — 응답의 `ml`(최상위)과 `verdicts[].ml`을 쓴다. 없거나 null·`enabled:false`여도 규칙 판정만으로 그린다.

| 상태 | 요약 영역 한 줄(cpu 아이콘, 쪽빛) | 행 |
|---|---|---|
| 미연결 `enabled:false` | "AIStream 판정 모델이 연결되지 않아 규칙 판정만 보여 줍니다." | 표시 없음 |
| 오류 `ok:false` | "…응답하지 않아 이번에는 규칙 판정만 보여 줍니다." (오류 원문은 title) | 표시 없음 |
| 정상 `ok:true` | "함께 검토했습니다. N개 중 M개가 규칙 판정과 같습니다." | 배지 아래 작은 "AI 등급": 규칙과 같으면 흐린 먹색, 다르면 등급 색+아이콘+확률 |

- **숨은 불가 경보**(`hidden_fail_alert`) 화면 이름은 **"불가 가능성"**. 뜻: 규칙으로는 불가가 아니지만 입력 자료가 부족한 상태라 모델은 실제로 불가일 가능성이 높다고 봄 → 원료 규격서·함량 자료 재확인.
  - 요약: 판정 문장 아래 경보 상자(흰 바탕 + fail-200 테두리 + 왼쪽 3px fail-700 막대 + circle-alert 아이콘) — 불가 배지(채움·팔각형)와 모양이 달라 판정 등급으로 오해되지 않는다.
  - 행: 인증명 옆 외곽선 태그 "불가 가능성"(circle-alert). 펼치면 맨 위에 경보 설명(규칙 등급, 모델의 불가 확률, 경보 기준), 메타에 "AI 모델 판정"과 확률 분포.
  - 개수는 현재 필터로 보이는 인증 기준으로 다시 센다. 회사 단위 인증은 모델 대상이 아니다(ml=null).

## 6. 컴포넌트 가이드

- **주 버튼**: brand-700 바탕·흰 글자, 높이 48px, 반경 sm. 호버 brand-800, 누름 `scale(.98)`. 로딩 시 비활성 + 회전 아이콘 + "판정 중". 화면당 주 버튼 1개(직접 입력의 "판정하기").
- **보조 버튼**: 흰 바탕 + field 테두리, 높이 44px.
- **데모 제품 버튼**: 작업대 위 목록(구분선으로 이은 한 덩어리, 개별 카드 아님). 선택 시 brand-100 바탕 + 왼쪽 3px brand-700 막대 + `aria-pressed="true"`. 처방 상태 태그(판매 중/시제품/기획)는 중성색(판정 색 금지).
- **탭**: `role="tablist"`, 화살표 키 이동, 선택 탭 아래 3px brand-700 선.
- **필터**: 라디오 칩 44px, 선택 시 brand-700 테두리 + brand-100 바탕 + 체크 아이콘. 칩마다 인증 수.
- **입력칸**: 높이 ≥44px, 테두리 field, 보이는 레이블, 도움말 상시 표시, 오류는 칸 바로 아래(`role="alert"`).
- **등급 범례 띠**: 4칸 한 줄(모바일 2×2), 칸마다 아이콘+등급명, 개수(32px/700), 정의(14px).
- **가장 먼저 할 일**: 번호 목록(우선순위라는 실제 순서), 행동 이름 + "인증 N개 공통" + 관련 인증·세부(시험 종류, 원료 수) + 범주 칩.
- **판정표 행**: 펼침 버튼 한 개가 행 전체(최소 높이 56px). 데스크톱은 [배지 | 인증명·핵심 사유 | 매트릭스 5칸 | 신뢰도 | 쉐브런], 모바일은 배지·신뢰도 위, 인증명, 사유, 보완 칩.
- **펼친 상세**: 범주 순(재처방 → 서류·확인 → 현지 책임자 → 문구·라벨 → 시험). 같은 코드·행동 3건 이상은 묶음("원료 기원·인증 확인 — 33종", 이름 목록 접기). 각 항목: 메시지 / 근거 / 해야 할 일. 참고(info)와 "불가 조건(카드 규칙)"은 `<details>`로 접음.
- **서류 초안**: 한 덩어리 목록(구분선), 행마다 파일 아이콘·이름·형식 태그(Word/Excel)·설명·내려받기 버튼. API 없으면 "준비 중"(비활성 + 이유 문구). "함량(%) 넣기" 체크(배합비는 영업 비밀 — 외부 제출용은 끔)를 `include_pct`로 보낸다.
- **상태 화면**: 빈 상태(등급 정의 + 안내 한 줄), 로딩(버튼 스피너 + `aria-busy`), 오류(원인 + "다시 시도" 버튼).

## 7. 카피 규칙

- 합니다체. 버튼은 동사: "판정하기", "내려받기", "다시 시도". 끝에 화살표 붙이지 않음.
- 용어 고정: 판정(평가·진단 혼용 금지), 인증·등록, 현지 책임자, 서류 초안, 예비 판정.
- 엔진 코드 문자열은 화면에서 한국어로: 표방 코드('whitening'→'미백'), 시험 코드(stability→안정성), `[kw:…]` 태그 제거, "EU_RP — " 역할 코드 접두 제거, "(추정)"은 유지.
- 고지문(항상 보임): "예비 판정입니다. 최종 판단은 각 기관과 자격 있는 안전성 평가자가 합니다."

## 8. 금기 목록 (Anti-patterns)

1. 판정을 색만으로 구분 (아이콘·글자 필수) — CRITICAL
2. 이모지 아이콘, 아이콘 패밀리 혼용, 채움/외곽선 혼용 — CRITICAL
3. raw hex를 토큰 정의부 밖에서 사용 — CRITICAL
4. 44px 미만 터치 타깃, 포커스 링 제거 — CRITICAL
5. AI 보라/분홍 그라데이션, 네온, 장난스러운 표현(신뢰 훼손) — HIGH
6. 다크 모드 기본값, 과한 애니메이션(자동 등장 효과 남발, 카운트업) — HIGH
7. 크림 바탕 + 테라코타, 같은 둥근 카드로 모든 내용 쪼개기, 카드마다 같은 회색 그림자 — HIGH
8. 모든 제목 위 대문자 눈썹 라벨, "A · B · C" 메타 문자열, 모노스페이스 소형 라벨, 버튼 끝 '→' — MEDIUM
9. 브랜드 색으로 판정 색(빨강·주황·초록) 사용, 처방 상태 태그에 판정 색 사용 — HIGH
10. 판정을 확정처럼 표현("인증 완료", "합격") — 항상 "예비 판정" — HIGH
