# 데이터 출처와 이용 조건

2026-11-07 운영진(퍼블릭에이아이) 데이터 검토 결과(46건)를 반영했다. 분류: 가능 / 출처 표기 시 가능 / 불가능.
**불가능** 자료는 저장소에 원문·표를 넣지 않는다. 인증 요건 카드(`data/certs/*.yaml`)는 공개 사실을 자체 문장으로 정리하고 원문 링크만 건다.

## 이용 불가로 빼거나 대체한 데이터

| 데이터 | 조치 |
|---|---|
| 중국 IECIC(2025 제61호)·화장품 안전기술규범 2015 | 표에서 삭제. 금지·제한은 식약처 API(15111772) 중국 행으로 대체, IECIC 등재는 '확인 필요' 안내 |
| 대만 TFDA 금지·제한·보존제·자외선·색소 목록 | 표에서 삭제. 식약처 API(15111772) 대만 행으로 대체 |
| COSMOS 표준·승인 원료 DB | 사용하지 않음. 공개 사실 기반 '천연·유기농 사전 점검' 카드로 대체 |
| NATRUE·영국 비건협회·V-Label·한국비건인증원·SFDA·캐나다 CNF·BPJPH·JCIA·PubChem·도쿄도 연구센터 | 원문·표를 넣지 않음. 카드에 공개 사실 요약과 원문 링크만(운영진에 활용 방식 회신 예정) |
