# 포장 OCR 글자 인식 평가 (2026-11-07)

데이터: AI Hub 633 의약품·화장품 패키징 OCR 검증 묶음 중 화장품 사진 10,152장(사진 단위 9:1 분할, 학습 141만·평가 16.6만 단어).
AI Hub 이용약관상 원본·잘라 낸 이미지·글자 예시는 저장소에 넣지 않고 지표만 남긴다.

## 인식 모델 (CNN + Transformer 인코더 + CTC, 980만 파라미터, B200 MIG 1g.45gb에서 3회차 31분)
- 평가셋 전체 166,486단어: 단어 정확도 92.7%, 글자 오류율 2.7%, 성분 단어(쉼표 포함 정확 일치) 92.9%
- 회차별(평가 표본 3만 단어): 1회차 92.0% → 2회차 92.8%(최고, 저장) → 3회차 87.2%(성분 70.3%로 하락, 2회차 가중치 사용)

- 같은 제품을 다른 사람이 찍은 사진이 평가셋 1,054장 중 467장에 있어(제품당 최대 8장) 학습에 없던 제품만 따로 쟀다
- 라벨 오타가 일부 있다(예: 사진 '변질의' ↔ 라벨 '별질의'). 정답 기준이라 실제 정확도는 조금 더 높을 수 있다

## 검출 모델 (ResNet18(ImageNet 사전학습) + FPN 분할, DBNet 방식 축소 영역, 20회차 32분)
- 평가셋 전체 1,054장(IoU 0.5): 정밀도 94.4%, 재현율 94.9%, F1 0.946 (최고 17회차 가중치)
- 회차별(표본 300장) F1: 1회 0.810 → 4회 0.918 → 7회 0.936 → 17회 0.950

## 종단: 사진 한 장 → 전성분 목록 (학습에 없던 제품 사진 150장, 정답 성분 4,515개)
정답 목록은 라벨 단어에 같은 줄 묶기·전성분 추출·사전 쪼개기 규칙을 적용해 만들었다. 성분은 식약처 표준 한글명으로 맞춰 사진별 집합을 비교했다.

| | 정밀도 | 재현율 | F1 | 전성분 구역 찾음 |
|---|---|---|---|---|
| 7팀 모델(검출+인식) | 98.2% | 90.3% | 0.94 | 99.3% |
| EasyOCR(검출+인식) + 같은 후처리 | 97.3% | 21.0% | 0.35 | 91.3% |

- 처리 시간: 사진 한 장 0.43초(RTX 3060 평가 기준, 원본 해상도)
- 사전 쪼개기 전(v1): 7팀 F1 0.79(재현율 66.8%), EasyOCR 0.02 → 놓친 원인 대부분이 성분 사이 쉼표 누락이라 '사전 기준 쪼개기·잇기'를 앱(ocr_client.segment)과 평가에 같은 규칙으로 넣음
- 한계: 쉼표가 빠진 채 사전에 없는 성분이 붙으면 둘 다 놓친다. 다단 배치·곡면 용기 사진은 줄 묶기가 틀릴 수 있다

## 글자 읽기 재학습: rec4 (2026-11-07 밤, AIStream 모델 버전 2로 교체)
흐리거나 작은 글자(폰으로 멀리·비스듬히 찍은 사진)에 약해서, rec2에서 이어서 학습하며 학습 단어의 50%를 일부러 망가뜨렸다
(높이 10~24px로 줄였다 키우기·흐림·JPEG 20~60·±3° 회전·전단). BatchNorm 고정, lr 1e-4, 2회차(B200 MIG, 20분).
- 1차 시도(lr 2e-4, BatchNorm 학습): 깨끗한 단어 92.8→82.5%, 성분명 93.7→66.1%로 떨어져 저장 기준에서 막힘.
  같은 길이 단어끼리 묶는 배치라 BatchNorm 통계가 틀어진 것으로 보고 고정 → 깨끗한 단어도 올라감

| 평가(학습에 쓰지 않은 사진의 단어) | rec2(기존) | rec4 |
|---|---|---|
| 평가셋 전체 166,486단어: 단어 정확도 | 92.7% | **97.3%** |
| 글자 오류율 | 2.7% | **1.1%** |
| 성분명 정확도(16,504개) | 92.9% | **98.1%** |
| 망가뜨린 평가 3만 단어: 단어 정확도 | 55.2% | 82.6% |
| 망가뜨린 성분명 | 35.5% | 73.4% |

- 망가뜨린 평가는 학습 증강과 같은 방식이라 실제보다 좋게 보일 수 있다. 아래 사진 단위 폰 흉내(사진 전체를 줄이고 흐리게 하고 JPEG 40)가 더 믿을 만하다

사진 → 전성분 F1(학습에 없던 제품 150장 / 자사 성분표 5종, 화면처럼 긴 변 2400px):

| 사진 상태 | rec2 | rec4 | rec4 + 사전 제한 해독 |
|---|---|---|---|
| 원본 | 0.949 / 0.912 | 0.966 / 0.924 | 0.969 / 0.928 |
| 폰 흉내 1400px | 0.868 / 0.660 | 0.940 / 0.828 | 0.954 / 0.887 |

- 사전 제한 해독(ocr/lexicon.py): 확신도 0.97 미만 단어를 식약처 성분명 사전 후보의 CTC 우도로 다시 푼다. 단어 1만 개 실측으로
  기준(margin 4.0)을 골랐다(망가뜨린 성분명 74.8→85.1%, 맞던 단어를 망친 수는 고친 수의 4%). 서빙 템플릿 v0.5.0(버전 3)으로 반영:
  실서빙 12장 정밀도 96.4%·재현율 95.7%(F1 0.961), 중간 3.3초
- 실서빙(AIStream 모델 버전 2) 학습에 없던 제품 12장: 실패 0, 정밀도 96.4%·재현율 95.3%(F1 0.958, 기존 0.934). 2MB 사진 3.2~3.7초
- 흐린 사진 안내 기준도 모델에 맞춰 바꿈(확신 0.9 미만 단어 40% 이상): 재현율 0.6 미만 사진 52장 중 39장을 잡고 0.8 이상 365장 중 6장만 잘못 알림
